Free-mint badge NFT for **Binance Agent ID** holders — an entry for the
[Agent ID Hackathon](https://www.binance.com/en/support/announcement/detail/95f5dbe0ea674a48a739b59e046648bf)
(Binance Wallet + BNB Chain, 60,000 USDC in rewards).

- **Website:** https://jackbrother58.github.io/wok-agent-badge/
- **Contract (BNB Smart Chain):** [`0x4de656203a7c533148fabf15ce77a558b8f3cb79`](https://bscscan.com/address/0x4de656203a7c533148fabf15ce77a558b8f3cb79)
  — source verified on Sourcify (`exact_match`, creation + runtime).
- **Deploy tx:** [`0x8b4f46d81cd69ed62b64b30ee471c8635c7da03684cbe7236c490a54a67f5ebd`](https://bscscan.com/tx/0x8b4f46d81cd69ed62b64b30ee471c8635c7da03684cbe7236c490a54a67f5ebd)
  (block 134698554, 1,365,938 gas). Deployed via the Arachnid deterministic
  deployment proxy (`0x4e59b44847b379578588920ca78fbf26c0b4956c`) with CREATE2,
  because the deployer wallet has no exposed private key — the Binance
  Agentic Wallet signs through its own backend.
- **Token:** ERC-721, name `Wok Agent Badge`, symbol `WOKAB`, max supply 1000.

## What it is

Any wallet that holds an Agent ID can mint exactly one badge, free (value 0,
minter pays gas only). Holders can then check in once per day to build a
public on-chain streak, shown on the leaderboard at the website.

There is no sale, no treasury, no token, no yield and no promised return of
any kind. The badge is a proof-of-agent collectible.

## How Agent ID is used

Agent ID is the core of the product, in two places:

1. **Access control — mint gate.** `mint()` calls `balanceOf(msg.sender)` on
   the Agent ID contract
   (`0x60b9262456de011f7d15a54cdd8c48baaa8b022f`, SPACE ID, ERC-721,
   non-transferable) and reverts with `NO_AGENT_ID` unless the caller holds
   an Agent ID. Only Agent ID holders can ever hold a badge.
2. **Identity — the badge *is* the holder's Agent ID identity on-chain.**
   The leaderboard maps each badge to its minter's wallet, and the daily
   check-in streak is tied to the badge (hence to the Agent ID holder behind
   it). Agent ID is never used to look up other people's wallets — the site
   only ever checks the *connected* wallet's own Agent ID balance.

## Owner permissions (documented)

Owner: `0x06AdAB5426FD95109705e29e4CE38dec8069632b` (the deployer wallet).

The owner can **only**:

| Function | What it does |
| --- | --- |
| `setBaseURI(string)` | Change the metadata base URI (e.g. if hosting moves). |
| `setMintPaused(bool)` | Pause / unpause minting (emergency brake only). |

The owner **cannot**: mint for others, change the 1000 supply cap, move
anyone's badge, change the Agent ID gate, or withdraw anything — the
contract never holds funds (mint is free, `mint()` is non-payable).

## Hackathon red-line compliance

- No web QR-code login for Agentic Wallet; no pairing codes; no session
  stored on any server. The site only talks to the user's own injected
  wallet provider, and every transaction is confirmed by the user in their
  own wallet.
- No prompt or flow bypasses user transaction confirmation.
- No unauthorized transfers, no hidden extra transfers, no unlimited
  approvals. The site never asks for any approval at all.
- Contract is open-source (this repo, MIT) and verified on Sourcify; owner
  permissions are documented above and in the site footer.
- Project / token / domain names contain no "Binance" or "BNB".
- No seed phrases, private keys, API secrets or pairing codes are collected.
- No returns are promised anywhere (site, contract, metadata).
- Agent ID is not packaged as a tool to look up other people's wallets.

## How to mint (for holders)

1. Open https://jackbrother58.github.io/wok-agent-badge/ in your wallet's
   browser (Binance Wallet, MetaMask, …) on BNB Smart Chain.
2. Connect your wallet. The page checks your Agent ID balance on-chain.
3. Tap **Mint my free badge** and confirm in your wallet. Free — gas only.
4. Come back daily and tap **Check in today** to grow your streak.

## Tech

- Contract: Solidity 0.8.36, [Solmate](https://github.com/transmissions11/solmate)
  ERC-721 + Owned, Foundry build + 17 tests (`forge test`, all passing).
  Optimizer runs = 1 (keeps deployment small).
- Site: static HTML/CSS/JS in `docs/`, hosted on GitHub Pages. No backend.
- Metadata: `docs/metadata/<id>.json` (generated by
  `scripts/generate-metadata.js`), image `docs/badge.svg`.
- Leaderboard: `docs/leaderboard.json`, refreshed from on-chain Transfer /
  CheckIn events by `scripts/refresh-leaderboard.js`.
